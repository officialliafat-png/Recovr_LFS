## Personal Website Description

Recovr is a lost-and-found web app that helps users reconnect with missing items by comparing uploaded photos against open reports. I built the backend with FastAPI, added real signup/login with salted password hashes and server-side sessions, then implemented an OpenCV matching pipeline that combines ORB feature matching, perceptual hashing, color histograms, and metadata bonuses to rank likely matches. Users can manage their own posts by editing details, updating status, or deleting stale reports. The project supports local SQLite development plus a hosted Supabase Postgres/Storage configuration and emphasizes clean API boundaries, contact privacy, deterministic tests with generated images, Docker setup, and clear documentation of production tradeoffs.
